Aplicativo de Viagens

Este projeto foi desenvolvido como parte da Somativa 1 da disciplina de Desenvolvimento Android. A proposta consiste em um aplicativo de viagens que apresenta diferentes destinos turísticos de maneira simples, organizada e visualmente agradável.

O aplicativo permite que o usuário acesse telas de login e criação de conta e, posteriormente, visualize uma lista de destinos disponíveis. Cada destino é apresentado em um card contendo imagem, nome da cidade e uma breve descrição do local.

A listagem foi implementada utilizando um RecyclerView, responsável por exibir os destinos de forma eficiente e reutilizável. Os dados de cada local são representados pela classe Lugar e organizados por meio de um Adapter, responsável por conectar as informações aos componentes visuais da interface.

Funcionalidades
Tela de login;
Tela de criação de conta;
Exibição de destinos turísticos;
Cards com imagem, nome, cidade e descrição;
Navegação entre as telas do aplicativo;
Listagem dinâmica utilizando RecyclerView;
Interface adaptada para dispositivos Android.
Tecnologias utilizadas
Kotlin;
Android Studio;
Android SDK;
XML para construção das interfaces;
RecyclerView;
Material Design;
ConstraintLayout e LinearLayout;
Programação orientada a objetos.

O projeto teve como objetivo aplicar conceitos fundamentais do desenvolvimento Android, como criação de Activities, navegação entre telas, construção de layouts, manipulação de componentes visuais e apresentação de dados em listas.
